# Diagram 1: Customer Transaction and Agent
## Purpose:
This diagram illustrates the flow of a currency exchange transaction. It explains from first registration fo customer till the final exchange of currency.  

## Key Actors:
 ### Customer :
 The user who initiates the process by providing their details for profile creation.

 ### Agent :
 The staff member responsible for verifying the customer's identity, performing the conversion, and providing receipt for the transaction.
